# BÔNUS: Ferramentas Essênciais

feito: No

Aqui estão as ferramentas que Eu utilizo e recomendo que você use para aumentar sua produtividade:

1. Canva 

- Criar capas para reels, carrosséis atrativos e designs para meus produtos digitais.

2. **Elementor** 

- Ferramenta que utilizo para criar sites bonitos de forma rápida para vender meus produtos.

3. Gumroad  

- Plataforma que uso para hospedar meus produtos gratuitos e coletar emails.

4. CapCut 

- Aplicativo que uso para editar meus vídeos e criar conteúdo.

5. ManyChat 

- Um dos melhores bots para automatizar o seu perfil do Instagram e fazendo-o responder comentários, enviar mensagens prontas com o link do seu produto, etc.

6. ChatGPT

- IA pra ajudar você a escrever seu  conteúdo, tirar idéias de ganchos, legejdas, e muito mais! (use muito)

7. Notion

- Ferramenta que você está usando agora. É uma das melhores ferramentas de anotações para se organizar em diversas áreas da sua vida e estrururar o seu calendário de posts semanais.
