## 🚀 Como Executar Localmente

Nenhum servidor pesado é necessário. Basta abrir os arquivos `.html` em qualquer navegador:

1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/guia-criador-digital.git
cd guia-criador-digital
```

2. Abra o Dashboard no navegador:
```bash
# No Linux:
xdg-open index.html

# Ou simplesmente dê um duplo clique em index.html
```
